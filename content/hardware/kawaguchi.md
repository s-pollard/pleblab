# kawaguchi

Media server and bulk-storage system in the production homelab.

## hardware

- UGREEN iDX6011 64GB AI NAS
- Intel Core Ultra 5 125H
- 64 GB memory
- 10 GbE uplink
- six HDDs in the Unraid array
- 2 × Samsung 970 EVO Plus 1 TB NVMe cache devices

## platform

Unraid 7.3.2

## role

Plex and media automation, manga, bulk media storage, and host-level monitoring.
